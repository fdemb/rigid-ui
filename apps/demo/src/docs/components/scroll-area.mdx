# Scroll area

Provides custom scrollbars while preserving native scrolling.

## Vertical scrolling

Give the scroll area a constrained height so its content can overflow. The viewport preserves native wheel, touch, and keyboard scrolling.

<Example title="Vertical scrolling" src={VerticalScrollAreaSource}>
  <VerticalScrollArea />
</Example>

## Both axes

Add a scrollbar for each axis when content can overflow in both directions. The corner occupies the space where the two scrollbars meet.

</Example>
