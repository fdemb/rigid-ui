# Button

Triggers an action, such as submitting a form or opening a dialog.

<Example title="Button preview" src={source}>
  <BasicButton />
</Example>

## Usage

Use `variant` to distinguish the primary action from secondary actions. Reserve `danger` for destructive actions. Set `type="submit"` when the button submits a form.

```tsx
<Button variant="primary" type="submit">
  Save changes
</Button>
```
