# Label

Identifies a form control and makes its text a clickable target.

<Example title="Label preview" src={source}>
  <BasicLabel />
</Example>

## Usage

Set `for` to the control's `id`. The `required` prop displays an asterisk; add `required` to the control itself to enable native validation.

```tsx
<Label for="name" required>Name</Label>
<Input id="name" required />
```
