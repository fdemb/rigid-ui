# Skeleton

Reserves space for content while it loads.

<Example title="Skeleton preview" src={source}>
  <BasicSkeleton />
</Example>

## Usage

Match the placeholder to the expected content with `shape`, `width`, and `height`. Skeletons are hidden from assistive technology; mark the containing region with `aria-busy` while loading.

```tsx
<div aria-busy="true" aria-label="Loading profile">
  <Skeleton shape="text" width="12rem" />
  <Skeleton height="5rem" />
</div>
```
