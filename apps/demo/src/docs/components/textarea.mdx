# Textarea

A multiline text field for messages, notes, and longer responses.

<Example title="Textarea preview" src={source}>
  <BasicTextarea />
</Example>

## Usage

Give the field a visible label. Set `rows` for its initial height; users can resize it vertically. Use `invalid` together with an associated error message when validation fails.

```tsx
<Label for="message">Message</Label>
<Textarea id="message" rows={4} placeholder="How can we help?" />
```
