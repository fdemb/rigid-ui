# Badge

Displays a short status or category alongside other content.

<Example title="Badge preview" src={source}>
  <BasicBadge />
</Example>

## Usage

Use `tone` to distinguish statuses. Always include a text label so that color is not the only way to tell them apart.

```tsx
<Badge tone="success">Ready</Badge>
```
