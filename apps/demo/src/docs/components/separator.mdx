# Separator

Separates groups of content horizontally or vertically.

<Example title="Separator preview" src={source}>
  <BasicSeparator />
</Example>

## Usage

Use `decorative` when the line adds no meaning for assistive technology. Set `orientation="vertical"` for a separator within a horizontal row.

```tsx
<Separator decorative />
```
