# Input

A single-line field for text, email addresses, and other form values.

<Example title="Input preview" src={source}>
  <BasicInput />
</Example>

## Usage

Associate each input with a `Label` using matching `id` and `for` values. Use `invalid` to mark a validation error and `aria-describedby` to connect the field to its error message.

```tsx
<Label for="email">Email</Label>
<Input id="email" type="email" placeholder="you@example.com" />
```
