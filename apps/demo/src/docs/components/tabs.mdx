# Tabs

Switches between related panels of content, one visible at a time.

<Example title="Tabs preview" src={barSource}>
  <BarTabs />
</Example>

## Usage

Give each `Tab` and its `Panel` the same `value`. Put `Indicator` inside `List`, after the tabs.
Label the list with `aria-label` when no visible heading names it.

```tsx
<Tabs.Root defaultValue="overview">
  <Tabs.List aria-label="Project">
    <Tabs.Tab value="overview">Overview</Tabs.Tab>
    <Tabs.Tab value="activity">Activity</Tabs.Tab>
    <Tabs.Indicator />
  </Tabs.List>
  <Tabs.Panel value="overview">…</Tabs.Panel>
  <Tabs.Panel value="activity">…</Tabs.Panel>
</Tabs.Root>
```

## Variants

`variant="bar"` is the default. It draws a rule under the list and a bar under the active tab, which suits page sections.
`variant="pill"` sets the tabs in a sunken track and raises the active one. Use it for compact switches such as a date range.

<Example title="Pill variant" src={pillSource}>
  <PillTabs />
</Example>

## Orientation

Set `orientation="vertical"` on `Root` to stack the tabs beside the panel. The arrow keys follow: Up and Down move focus instead of Left and Right.
This example also sets `activateOnFocus`, so moving focus selects the tab.

<Example title="Vertical tabs" src={verticalSource}>
  <VerticalTabs />
</Example>

## Styling

The indicator reads the active tab's position and size from CSS variables, so it slides between tabs and follows them when they resize.
The motion is off when the user prefers reduced motion.
Each part accepts `xstyle`, `class`, and `style` overrides.

For unstyled parts and the full behavioral API, see the <Link href="/primitives/tabs">Tabs primitive</Link>.
