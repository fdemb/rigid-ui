# Card

Groups related content with an optional header and footer.

<Example title="Card preview" src={source}>
  <BasicCard />
</Example>

## Usage

Compose `CardHeader`, `CardBody`, and `CardFooter` inside `Card`. Use `CardTitle` for the heading and `CardDescription` for supporting text.

```tsx
<Card>
  <CardHeader>
    <CardTitle>Project settings</CardTitle>
    <CardDescription>Manage your project.</CardDescription>
  </CardHeader>
  <CardBody>Project details</CardBody>
</Card>
```
