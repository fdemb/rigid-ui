# Card

Groups related content with an optional header and footer.

<Example title="Card preview" src={source}>
  <BasicCard />
</Example>

## Usage

Compose `CardHeader`, `CardContent`, and `CardFooter` inside `Card`. Put `CardTitle` and `CardDescription` in the header, and `CardAction` for a badge or button at the end of the header. Set `divided` on a header or footer to draw a line between it and the content.

```tsx
<Card>
  <CardHeader>
    <CardTitle>Project settings</CardTitle>
    <CardDescription>Manage your project.</CardDescription>
    <CardAction>
      <Badge>Draft</Badge>
    </CardAction>
  </CardHeader>
  <CardContent>Project details</CardContent>
  <CardFooter>
    <Button variant="outline">Cancel</Button>
    <Button>Save</Button>
  </CardFooter>
</Card>
```
