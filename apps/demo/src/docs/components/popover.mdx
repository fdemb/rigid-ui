# Popover

Displays interactive content next to a trigger.

## Basic usage

Use a popover for a small form or contextual controls that should leave the rest of the page available.

<Example title="Basic usage" src={BasicPopoverSource}>
  <BasicPopover />
</Example>

## Open on hover

Set `openOnHover` to open the popup when the pointer rests on the trigger. The popup remains open while the pointer moves over its content.

<Example title="Open on hover" src={HoverPopoverSource}>
  <HoverPopover />
</Example>

## Custom styling

Pass `xstyle` to override a component's styles with StyleX. Keep focus and disabled states visible when changing the appearance.

<Example title="Custom styling" src={ComposedPopoverSource}>
  <ComposedPopover />
</Example>

## Shared popup

Several triggers can share one popup. Each trigger supplies a payload, and the popup moves to the active trigger. Read payload values through the render callback argument to preserve reactivity.

<Example title="Shared popup" src={SharedTriggerPopoverSource}>
  <SharedTriggerPopover />
</Example>
