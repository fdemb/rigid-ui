# Progress

Shows task completion, such as an upload or download. This primitive is unstyled.

## Import

```tsx
import { Progress } from "rigid-ui/primitives/progress";
```

## Anatomy

Progress is composed of the following parts. This example shows their structure; add your own styles to make the result visible and usable.

```tsx
<Progress.Root value={64}>
  <Progress.Label>Upload progress</Progress.Label>
  <Progress.Value />
  <Progress.Track>
    <Progress.Indicator />
  </Progress.Track>
</Progress.Root>
```

## Behavior

`Root` accepts a numeric `value`. Without a `value`, it enters indeterminate mode.
The range defaults to `min={0}` and `max={100}`.
The indicator width and default percentage text describe the value's position within that range.
Out-of-range values are clamped. `NaN` uses the minimum value and an empty indicator.

`Label` supplies the progressbar's accessible name. Its association updates when its ID changes and clears when it unmounts.
Without a `Label`, provide `aria-label` or `aria-labelledby` on `Root`.

`format` accepts `Intl.NumberFormat` options and formats the clamped numeric value instead of its percentage.
`locale` selects the formatting locale. Both the visible value and `aria-valuetext` use the same formatted text.

`getAriaValueText(formattedValue, value)` customizes the accessible value text.
`Value` also accepts a child function with those arguments. Both callbacks receive the original, unclamped numeric value.

## Styling

Pass classes or styles to individual parts. The primitive handles behavior and accessibility without supplying a visual theme.
