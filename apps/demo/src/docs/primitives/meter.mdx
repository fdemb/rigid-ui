# Meter

Displays a measurement within a known range, such as storage usage or battery level. This primitive is unstyled.

## Import

```tsx
import { Meter } from "rigid-ui/primitives/meter";
```

## Anatomy

Meter is composed of the following parts. This example shows their structure; add your own styles to make the result visible and usable.

```tsx
<Meter.Root value={64}>
  <Meter.Label>Storage usage</Meter.Label>
  <Meter.Value />
  <Meter.Track>
    <Meter.Indicator />
  </Meter.Track>
</Meter.Root>
```

## Behavior

`Root` requires a numeric `value`. The range defaults to `min={0}` and `max={100}`.
The indicator width and default percentage text describe the value's position within that range.
Out-of-range values are clamped. `NaN` uses the minimum value and an empty indicator.

`Label` supplies the meter's accessible name. Its association updates when its ID changes and clears when it unmounts.
Without a `Label`, provide `aria-label` or `aria-labelledby` on `Root`.

`format` accepts `Intl.NumberFormat` options and formats the clamped numeric value instead of its percentage.
`locale` selects the formatting locale. Both the visible value and `aria-valuetext` use the same formatted text.

`getAriaValueText(formattedValue, value)` customizes the accessible value text.
`Value` also accepts a child function with those arguments. Both callbacks receive the original, unclamped numeric value.
